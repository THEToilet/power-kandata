# パワーカンダタ

芥川龍之介「蜘蛛の糸」を題材にした、縦スクロールのアクションゲームです。
地獄の底から一本の蜘蛛の糸を登り、1000m 上の極楽を目指します。

しがみついてくる罪人たちを **叫んで蹴落とし、踏み台にして跳ぶ**。
溜めるほど高く跳べるけれど、大勢ぶら下がるほど糸は傷んで切れやすくなる……というチキンレースです。

## 遊び方

| 操作 | キーボード | パッド |
| --- | --- | --- |
| 登る | W / ↑ | 左スティック上 / 右トリガー |
| 糸を揺らす（よける） | A / D | 左スティック左右 |
| 叫ぶ（罪人を蹴落として跳ぶ） | SPACE | A / B（× / ○） |
| スタート / リトライ | SPACE / Enter | A / START |
| 音のオン・オフ | M | — |
| クレジット（タイトル画面） | C | Y |

- カンダタ一人なら糸は傷みません。傷めるのは、しがみついた罪人たちです。
- 糸が切れる寸前（残り1割未満）で叫ぶと「九死に一生」。いつもより大きく跳べます。
- 下からマグマが迫ってきます。跳んで引き離しましょう。
- 鬼が崖から岩を投げ、鬼火が円を描いて回っています。糸を揺らしてよけてください。跳んでいる間は無敵です。
- 極楽に着いたらクリア。クリアタイムの上位10件がランキングに残ります。

## 開発

- エンジン: [Godot](https://godotengine.org/) 4.6.3
- 絵はすべてコードで描いたドット絵、音は `tools/make_audio.py` で合成しています（外部素材なし）。

| ファイル | 中身 |
| --- | --- |
| `main.gd` | 画面・演出・入力・音 |
| `thread_model.gd` | ゲームのルール（糸、罪人、跳躍、障害物、マグマ） |
| `sim_test.gd` | ボットを走らせてバランスを確認する（`godot --headless --path . -s sim_test.gd`） |
| `tools/capture.gd` | ボットに自動プレイさせてスクリーンショットを撮る |
| `tools/make_audio.py` | BGM・効果音を合成して `audio/` に書き出す（numpy / scipy） |
| `run_game.bat` / `open_editor.bat` | Windows 用の起動スクリプト。Godot の場所を `godot_path.txt` に1行で書いておく（git には入らない） |

`main.gd` 先頭の `DEV_TOOLS` を `true` にすると、開発用の調整パネル（F1）と、プレイ中のやり直し（R / N）が使えます。
